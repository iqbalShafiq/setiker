# Pull Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add server-to-device pull sync for sticker packs and stickers without overwriting pending local edits.

**Architecture:** Extend `SyncManagerImpl` so `sync()` pushes local queue first, then pulls `/api/v1/sync`. Add focused import helpers for cloud models, persisted sync cursor storage, and clearer sync stage/result state for UI.

**Tech Stack:** Kotlin Multiplatform, Room, DataStore Preferences, Ktor client, WorkManager, Compose Multiplatform, kotlin.test.

---

## Files

- Modify `composeApp/src/commonMain/kotlin/data/remote/model/CloudModels.kt`: add complete cloud sync DTOs for packs, pack-sticker relations, stickers, owners, and deleted refs.
- Modify `composeApp/src/commonMain/kotlin/data/remote/CloudStickerRepository.kt`: send `lastSyncAt` as ISO string and decode `SyncData` with richer DTOs.
- Create `composeApp/src/commonMain/kotlin/data/sync/SyncCursorStore.kt`: persist decoded server sync timestamp in DataStore.
- Modify `composeApp/src/commonMain/kotlin/di/AppModule.kt`: provide `SyncCursorStore`, pass it and `StickerDao`/`StickerFileStorage` into `SyncManagerImpl`.
- Modify `composeApp/src/commonMain/kotlin/data/local/database/StickerDao.kt`: add cloud-id lookup and delete helpers.
- Modify `composeApp/src/commonMain/kotlin/data/sync/SyncManagerImpl.kt`: add pull sync, import/update/delete logic, conflict guard, and stage reporting.
- Modify `composeApp/src/commonMain/kotlin/domain/model/SyncReport.kt`: add downloaded counts and stage enum.
- Modify `composeApp/src/commonMain/kotlin/presentation/sync/SyncState.kt`: expose stage text and downloaded counts.
- Modify `composeApp/src/commonMain/kotlin/presentation/sync/SyncScreen.kt`: display clearer sync UX copy.
- Add tests under `composeApp/src/commonTest/kotlin/data/sync/` for sync token decoding, import decision helpers, and conflict guard.
